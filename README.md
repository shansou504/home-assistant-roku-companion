## Description

Control Home Assistant devices from Roku using the native Home Assistant API. Currently only ```binary_sensor```, ```switch```, and  ```light``` domains are available.

## Instructions

Using the **Server** and **Token** menu items on the home screen:

1. Add your Home Assistant host IP and port. For example ```http(s)://192.168.1.2:8123```.
2. Add your Home Assistant user's [Long-lived access token](https://developers.home-assistant.io/docs/auth_api/#long-lived-access-token). ***Use the [Roku mobile app](https://www.roku.com/mobile-app) or your phone's camera to scan the QR code on Roku's keyboard to paste your Home Assistant token.***
